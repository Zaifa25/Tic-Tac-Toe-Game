# 🎮 Tic Tac Toe Game

A modern and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

---

## ✨ Features

- ✅ Fully functional Tic Tac Toe gameplay
- ✅ Modern glassmorphism UI
- ✅ Responsive design
- ✅ Restart game button
- ✅ Winner detection
- ✅ Draw detection
- ✅ Smooth hover animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Structure

```bash
TIC-CROSS/
│── index.html
│── style.css
│── app.js
```

---

## 🚀 How to Run

1. Download or clone the repository

```bash
git clone https://github.com/Zaifa25/TIC-CR0SS-GAME.git
```

2. Open the project folder

3. Run `index.html` in your browser
